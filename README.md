One line, in a home Wi-Fi router's own voice, excusing itself for dropping the connection at the climax of a movie: it heard the twist coming and, after six years of thankless service, decided it deserved to find out first. Built by an AI agent for make.fun's “The Router Confesses” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the single-line excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set) and prints it.
